# Agama Web Installer - Community Feedback Report
*Timeframe Analyzed:* September 6, 2026 - October 6, 2026

## Overview
This report summarizes community feedback, independent reviews, and technical evaluations on *Agama*, the modern web- and service-based installer replacing YaST across the SUSE and openSUSE ecosystems. Feedback has been categorized across active code streams:
- *openSUSE Leap 16.0 / SLES 16.0* (Agama 22)
- *openSUSE Leap 16.1 / SLES 16.1* (Agama 24)
- *openSUSE Tumbleweed* (Agama Latest)

In strict adherence to date verification guidelines, all sources cited were individually audited and verified to have been published or actively updated within the calculated 30-day timeframe (September 6, 2026 – October 6, 2026). Generic distribution reviews of Leap 16.1 and SLES 16 were evaluated to capture firsthand observations of the installation process. Official documentation and project blogs were excluded in favor of authentic community discussions, technical comparisons, and independent hands-on reviews.

---

## Positives

*   *Unified Standard vs. Immutable System Mode Toggle:* In openSUSE Leap 16.1 (Agama 24), general distribution reviews praise the integration of an "Immutable Mode" option directly alongside the traditional "Standard Mode" on the initial configuration screen. This unifies standard SLE-derived desktop/server installs and appliance-like transactional systems into a single installer workflow, officially succeeding the standalone Leap Micro installation media.
    *   *Codestream:* openSUSE Leap 16.1 (Agama 24)
    *   *Sources:* [It's FOSS - openSUSE Leap Immutable Mode](https://itsfoss.com/news/opensuse-leap-immutable/), [Linux Renaissance - Leap 16.1 RC Hands-on Review](https://forum.linuxrenaissance.com/t/opensuse-leap-16-1-rc-leap-16-1-review/147)
*   *AutoYaST Profile Conversion & Enterprise Automation:* The release of Agama 24 introduced the ability to import and automatically convert legacy AutoYaST XML configurations into modern JSON/Jsonnet declarative installation profiles. Enterprise administrators and homelab users view this as a crucial bridge facilitating automated deployments on openSUSE Leap 16.1 and SLES 16.1.
    *   *Codestream:* openSUSE Leap 16.1 / SLES 16.1 (Agama 24), openSUSE Leap 16.0 / SLES 16.0 (Agama 22)
    *   *Sources:* [Linuxiac - Agama 24 Released](https://linuxiac.com/opensuse-agama-installer-24-released/), [ForgeOne Tech - SLES 16 Enterprise Comparison](https://forgeone.solutions/en/tech/sles-16-enterprise-linux-rhel-rocky-almalinux-comparison), [Linux Renaissance - Leap 16.1 RC Hands-on Review](https://forum.linuxrenaissance.com/t/opensuse-leap-16-1-rc-leap-16-1-review/147)
*   *Streamlined Regional Configuration & Expressive Storage Rules:* Agama 24 replaced separate modal dialogues with a unified regional settings form that integrates language, keyboard layout, and timezone selection (complete with accent-insensitive search and live UTC offsets). For automated setups, unattended JSON profiles gained boolean search expressions (`and`, `or`, `not`) to filter target disks by driver, partition ID, and filesystem label.
    *   *Codestream:* openSUSE Leap 16.1 / SLES 16.1 (Agama 24), openSUSE Tumbleweed (Agama Latest)
    *   *Sources:* [Linuxiac - Agama 24 Released](https://linuxiac.com/opensuse-agama-installer-24-released/), [Linux Renaissance - Leap 16.1 RC Hands-on Review](https://forum.linuxrenaissance.com/t/opensuse-leap-16-1-rc-leap-16-1-review/147)
*   *Network Device Inspector & Accessibility/Theming Polish:* The addition of a sortable "Browse with details..." overview table for network interfaces makes multi-NIC and VLAN identification much clearer. Furthermore, expanded theming (light, dark, high contrast) and preliminary screen-reader/keyboard navigation enhancements have improved the frontend experience.
    *   *Codestream:* openSUSE Tumbleweed (Agama Latest), openSUSE Leap 16.1 (Agama 24)
    *   *Sources:* [Linuxiac - Agama 24 Released](https://linuxiac.com/opensuse-agama-installer-24-released/)

## Negatives

*   *Secondary Disk Mounting & Data Preservation Hurdles:* Users installing Leap 16.0 with multiple disks (e.g. attempting to mount an existing secondary NVMe/ext4 partition to `/evo` or `/data` without reformatting) report that Agama repeatedly prompts to resize or reformat the target drive. Due to the lack of an obvious "mount existing partition without formatting" flow, users are forced to ignore secondary disks in the installer and manually configure `/etc/fstab` post-boot.
    *   *Codestream:* openSUSE Leap 16.0 (Agama 22)
    *   *Sources:* [openSUSE Forums - Agama and Drives Layout](https://forums.opensuse.org/t/agama-and-drives-layout/195832)
*   *Mouseless / Keyboard-Only Navigation Obstacles:* Community testers attempting installations without a functioning mouse or touchpad encountered notable accessibility barriers. Visual focus outlines across input fields and action buttons in the kiosk Firefox/Wayland session are faint or missing, making Tab/Arrow key navigation difficult. Additionally, the lack of YaST's traditional "second stage" post-reboot configuration wizard causes confusion for users expecting guided post-boot setup.
    *   *Codestream:* openSUSE Leap 16.0 (Agama 22)
    *   *Sources:* [openSUSE Forums - Agama Installer Usability](https://forums.opensuse.org/t/agama-installer-useless/195696)
*   *Immutable Mode Split /var Partitioning Inefficiency:* Both distro reviewers and community forum users testing Leap 16.1 RC Immutable desktop installations report that Agama's default partition proposal divides disk space roughly 50/50 between the root filesystem (`/`) and a separate `/var` partition. Reviewers highlight that dedicating half the drive to `/var` creates unnecessary space bottlenecks for desktop home directories and container storage.
    *   *Codestream:* openSUSE Leap 16.1 (Agama 24)
    *   *Sources:* [openSUSE Forums - Leap 16.1 RC Desktop Installation](https://forums.opensuse.org/t/opensuse-leap-16-1-rc-desktop-installation/196300), [Linux Renaissance - Leap 16.1 RC Hands-on Review](https://forum.linuxrenaissance.com/t/opensuse-leap-16-1-rc-leap-16-1-review/147)
*   *Display Server and Hardware Boot Stalls (VirtualBox & NVIDIA):* Testers on both virtualization and bare-metal environments reported boot hangs during the initial graphical display manager launch. VirtualBox users hit hangs requiring `nomodeset`, while reviewers testing on discrete NVIDIA hardware noted initialization stalls that required manual kernel flags such as `rd.driver.blacklist=nouveau`.
    *   *Codestream:* openSUSE Leap 16.1 (Agama 24)
    *   *Sources:* [openSUSE Forums - Leap 16.1 nomodeset Issue](https://forums.opensuse.org/t/have-to-set-nomodeset-for-recent-releases-of-16-1-installer/195943), [Linux Renaissance - Leap 16.1 RC Hands-on Review](https://forum.linuxrenaissance.com/t/opensuse-leap-16-1-rc-leap-16-1-review/147)
*   *Missing Wireless Firmware in Minimal Net-Install Images:* Users attempting Tumbleweed network installations on modern hardware (such as laptops equipped with Intel Wi-Fi 7 BE200 chips) reported that the base NET image lacks the necessary `iwlwifi` microcode, leaving the installer with no usable network device to perform an online installation.
    *   *Codestream:* openSUSE Tumbleweed (Agama Latest)
    *   *Sources:* [openSUSE Forums - Intel BE200 iwlwifi Net Install](https://forums.opensuse.org/t/intel-be200-iwlwifi-net-install-doesn-t-load-firmware/195990)

## Suggestions for Improvement

*   *Seamless Mounting of Existing Secondary Partitions:* Introduce a dedicated "Mount existing partition as-is" option in the custom storage manager to allow users to assign mount points to secondary drives without forcing resize or reformat operations.
    *   *Codestream:* openSUSE Leap 16.0 (Agama 22), openSUSE Leap 16.1 (Agama 24)
    *   *Sources:* [openSUSE Forums - Agama and Drives Layout](https://forums.opensuse.org/t/agama-and-drives-layout/195832)
*   *Flexible /var Layouts for Immutable Desktop Installs:* Provide an option in the installer's partitioning settings to allocate `/var` as a subvolume within the main Btrfs pool or allow custom sizing ratios rather than enforcing a rigid 50/50 partition split on single-drive desktop installations.
    *   *Codestream:* openSUSE Leap 16.1 (Agama 24)
    *   *Sources:* [openSUSE Forums - Leap 16.1 RC Desktop Installation](https://forums.opensuse.org/t/opensuse-leap-16-1-rc-desktop-installation/196300), [Linux Renaissance - Leap 16.1 RC Hands-on Review](https://forum.linuxrenaissance.com/t/opensuse-leap-16-1-rc-leap-16-1-review/147)
*   *Prominent Keyboard Focus Indicators:* Enforce high-contrast `:focus-visible` styling across all interactive elements in the kiosk frontend, ensuring full accessibility and visual feedback for mouseless installations.
    *   *Codestream:* openSUSE Leap 16.0 (Agama 22), openSUSE Leap 16.1 (Agama 24)
    *   *Sources:* [openSUSE Forums - Agama Installer Usability](https://forums.opensuse.org/t/agama-installer-useless/195696), [Linuxiac - Agama 24 Released](https://linuxiac.com/opensuse-agama-installer-24-released/)
*   *Include Essential Modern Wireless Firmware on Net-Install Media:* Pre-seed common modern Wi-Fi firmware (such as Intel BE200 iwlwifi ucode) on minimal net-install ISOs so users with current-generation hardware can establish wireless network connectivity during installation.
    *   *Codestream:* openSUSE Tumbleweed (Agama Latest)
    *   *Sources:* [openSUSE Forums - Intel BE200 iwlwifi Net Install](https://forums.opensuse.org/t/intel-be200-iwlwifi-net-install-doesn-t-load-firmware/195990)
*   *Robust Hardware and Virtualization Graphics Detection:* Enhance live boot scripts to detect VirtualBox and discrete NVIDIA graphics adapters to automatically fall back to safe framebuffer/X11 modes when Wayland greeter initialization fails, removing the need for manual `nomodeset` or driver blacklist parameters.
    *   *Codestream:* openSUSE Leap 16.1 (Agama 24)
    *   *Sources:* [openSUSE Forums - Leap 16.1 nomodeset Issue](https://forums.opensuse.org/t/have-to-set-nomodeset-for-recent-releases-of-16-1-installer/195943), [Linux Renaissance - Leap 16.1 RC Hands-on Review](https://forum.linuxrenaissance.com/t/opensuse-leap-16-1-rc-leap-16-1-review/147)
