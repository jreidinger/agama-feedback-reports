# Agama Web Installer - Community Feedback Report
*Timeframe Analyzed:* October 6, 2026 - November 3, 2026

## Overview
This report synthesizes community feedback, independent hands-on reviews, and technical evaluations for **Agama**, the modern web- and service-based installer replacing YaST across the SUSE and openSUSE ecosystems. Feedback has been categorized across active code streams:
- *openSUSE Leap 16.0 / SLES 16.0* (Agama 22)
- *openSUSE Leap 16.1 / SLES 16.1* (Agama 24)
- *openSUSE Tumbleweed* (Agama 25 / Latest)

In strict adherence to date verification guidelines, all sources cited were individually audited and verified to have been published or actively updated within the timeframe spanning the end of the previous report through today (October 6, 2026 – November 3, 2026). Distribution reviews and release coverage of openSUSE Leap 16.1 GA (officially released November 3, 2026) were evaluated alongside upstream Agama 25 release analysis and community forum discussions. Official documentation and project blogs were excluded in favor of authentic community discussions, third-party technical publications, and independent reviews.

## Positives

*   **Integrated In-Browser Web Terminal:** In the newly released Agama 25, users and administrators gained access to an interactive terminal embedded directly within the web UI. Previously, inspecting errors, viewing logs, or executing diagnostic commands required switching to a secondary virtual console (`Ctrl+Alt+F8`) or setting up an SSH session. Testers and reviewers heavily praised this addition for streamlining real-time troubleshooting inside virtual machines and remote sessions.
    *   *Codestream:* openSUSE Tumbleweed (Agama 25 / Latest)
    *   *Sources:* [Linuxiac - openSUSE’s Agama 25 Installer Adds Web Terminal, Improves Networking](https://linuxiac.com/opensuses-agama-25-installer-adds-web-terminal-improves-networking/), [WiseVoter - openSUSE Project Releases Agama 25 Installer](https://wisevoter.com/world/2026/10/23/opensuse-releases-agama-25-installer), [YouTube - Low Tech Linux: Agama 25 and the future of YaST](https://www.youtube.com/watch?v=jF7rS2KUtNs)
*   **Pre-Installation Exit and Abort Functionality:** Addressing a prominent complaint from earlier testing cycles where users were unable to cancel without performing a hard power cut, Agama 25 introduced explicit exit, reboot, and shutdown controls on the configuration screen. The installer automatically disables this option once disk modification begins to safeguard against leaving partitions in an unbootable or corrupted state.
    *   *Codestream:* openSUSE Tumbleweed (Agama 25 / Latest)
    *   *Sources:* [Linuxiac - openSUSE’s Agama 25 Installer Adds Web Terminal, Improves Networking](https://linuxiac.com/opensuses-agama-25-installer-adds-web-terminal-improves-networking/), [Tux Machines - openSUSE Releases Agama 25 Installer](https://news.tuxmachines.org/n/2026/10/22/openSUSE_Releases_Agama_25_Installer_with_Web_Based_Terminal_Ex.shtml), [YouTube - Low Tech Linux: Agama 25 and the future of YaST](https://www.youtube.com/watch?v=jF7rS2KUtNs)
*   **Unified Distribution Architecture with Immutable Mode Integration:** With openSUSE Leap 16.1 officially launching into General Availability on November 3, 2026 (synchronized with SLES 16.1), the Agama 24 installer successfully absorbed the standalone Leap Micro distribution into the primary Leap release. Users booting the standard Leap 16.1 installer media can seamlessly select between traditional mutable deployment and an "Immutable Mode" backed by a read-only Btrfs root filesystem, transactional updates (`transactional-update`), and Snapper rollbacks.
    *   *Codestream:* openSUSE Leap 16.1 / SLES 16.1 (Agama 24)
    *   *Sources:* [LinuxCompatible - openSUSE Leap 16.1 Released: Immutable Mode and Unified Distro Ship Now](https://www.linuxcompatible.org/story/opensuse-leap-161-released-immutable-mode-and-unified-distro-ship-now/), [Linuxiac - openSUSE Leap 16.1 Released with Immutable Mode, KDE Plasma 6.6](https://linuxiac.com/opensuse-leap-16-1-released-with-immutable-mode-kde-plasma-6-6/), [YouTube - Immutable Mode tutorial OpenSUSE Leap 16.1](https://www.youtube.com/watch?v=3Qq-_uDRFDg)
*   **Modern Authentication Defaults (Passwordless Root & Sudo Wheel):** Community members on Tumbleweed praised Agama's flexible security model for privilege escalation. While legacy YaST enforced setting a distinct root password during installation, Agama allows users to omit the root password entirely, automatically granting administrative privileges to the primary user via wheel group sudo policy (`sudo-policy-wheel-auth-self`), modernizing the default security posture.
    *   *Codestream:* openSUSE Tumbleweed (Agama Latest)
    *   *Sources:* [openSUSE Forums - Agama offline installation media and installer defaults](https://forums.opensuse.org/t/agama-offline-installation-media-and-installer-defaults/196616)
*   **Searchable Multi-Select Network Bonding & Interface Configuration:** Agama 25 replaced free-form text input fields for bonded and bridged interface slave selection with a searchable, filterable multi-selection UI that dynamically lists detected physical adapters while retaining manual input support for virtual or unprobed interfaces.
    *   *Codestream:* openSUSE Tumbleweed (Agama 25 / Latest)
    *   *Sources:* [Linuxiac - openSUSE’s Agama 25 Installer Adds Web Terminal, Improves Networking](https://linuxiac.com/opensuses-agama-25-installer-adds-web-terminal-improves-networking/), [WiseVoter - openSUSE Project Releases Agama 25 Installer](https://wisevoter.com/world/2026/10/23/opensuse-releases-agama-25-installer)
*   **API Standardization & Architecture Expansion:** The upstream project published stable, versioned URLs for OpenAPI specifications and JSON schemas, significantly simplifying unattended enterprise provisioning. Additionally, initial baseline support was added for 32-bit and `riscv64` installation media targets, while AutoYaST conversion logic was migrated natively into the core Agama codebase.
    *   *Codestream:* openSUSE Tumbleweed (Agama 25 / Latest), openSUSE Leap 16.1 / SLES 16.1 (Agama 24)
    *   *Sources:* [WiseVoter - openSUSE Project Releases Agama 25 Installer](https://wisevoter.com/world/2026/10/23/opensuse-releases-agama-25-installer), [Tux Machines - openSUSE Releases Agama 25 Installer](https://news.tuxmachines.org/n/2026/10/22/openSUSE_Releases_Agama_25_Installer_with_Web_Based_Terminal_Ex.shtml)

## Negatives

*   **Absence of Offline Media & WPA2-Enterprise Connectivity Hurdles:** Users installing openSUSE Tumbleweed in restricted wireless environments (e.g., enterprise or academic 802.1X/WPA2-Enterprise networks) report being unable to authenticate or connect within the installer. Because Agama images for Tumbleweed strictly rely on online repository fetching rather than providing full offline snapshot packages, users without an open network connection cannot complete the installation or utilize the ISO as a system rescue tool.
    *   *Codestream:* openSUSE Tumbleweed (Agama Latest)
    *   *Sources:* [openSUSE Forums - Agama offline installation media and installer defaults](https://forums.opensuse.org/t/agama-offline-installation-media-and-installer-defaults/196616)
*   **Missing Console/Ncurses Text-Based Installer Fallback:** In Leap 16.0 and 16.1, users operating legacy KVM hardware (such as low-resolution Tripp Lite console switches) or headless server consoles report that graphical initialization results in a blank screen, with the "failsafe" boot option failing to display. Because the classic YaST ncurses text-mode installer was removed, and security policies in air-gapped environments forbid inbound HTTP connections to `https://agama.local` before the OS is installed, users have no means to perform a local interactive installation.
    *   *Codestream:* openSUSE Leap 16.0 / SLES 16.0 (Agama 22), openSUSE Leap 16.1 / SLES 16.1 (Agama 24)
    *   *Sources:* [openSUSE Forums - Text-based Installation of Leap 16?](https://forums.opensuse.org/t/text-based-installation-of-leap-16/196983)
*   **Partitioning Friction & systemd-boot EFI Sizing Warnings:** New users configuring manual partitioning schemes on Tumbleweed encountered boot failures and blocking warnings. Under Agama's adoption of `systemd-boot` and the Boot Loader Specification (BLS), the installer requires a 2 to 4 GiB `/boot/efi` partition. Users reusing existing 1 GiB EFI system partitions reported confusing loop prompts stating the system will not boot, without clear in-UI guidance on how to adjust sizes.
    *   *Codestream:* openSUSE Tumbleweed (Agama Latest)
    *   *Sources:* [openSUSE Forums - Newish to opensuse, doubts about yast and partitions](https://forums.opensuse.org/t/newish-to-opensuse-doubts-about-yast-and-partitions/196981), [openSUSE Forums - RE: YaST Gone Now What?](https://forums.opensuse.org/t/re-yast-gone-now-what/196979)
*   **Irreversible Mode Selection & Experimental Micro Migration:** Distro reviewers and testers highlight that the selection between Traditional Mode and Immutable Mode in Leap 16.1 must be decided irrevocably at install time in Agama. Furthermore, sysadmins upgrading existing Leap Micro 6.2 systems to Leap 16.1 Immutable Mode note that the automated `opensuse-migration-tool` remains experimental and lacks support for versions prior to 6.2.
    *   *Codestream:* openSUSE Leap 16.1 / SLES 16.1 (Agama 24)
    *   *Sources:* [LinuxCompatible - openSUSE Leap 16.1 Released: Immutable Mode and Unified Distro Ship Now](https://www.linuxcompatible.org/story/opensuse-leap-161-released-immutable-mode-and-unified-distro-ship-now/), [Linuxiac - openSUSE Leap 16.1 Released with Immutable Mode, KDE Plasma 6.6](https://linuxiac.com/opensuse-leap-16-1-released-with-immutable-mode-kde-plasma-6-6/)
*   **Community Friction Regarding YaST Deprecation in Default Patterns:** Late-October Tumbleweed snapshots finalized the removal of legacy YaST packages from default installation patterns (`enhanced_base`, desktop roles). Long-time users and forum participants expressed vocal dissatisfaction with the transition, lamenting the loss of familiar monolithic system management modules and citing apprehension over moving to browser-based Agama and Cockpit workflows.
    *   *Codestream:* openSUSE Tumbleweed (Agama Latest)
    *   *Sources:* [openSUSE Forums - RE: YaST Gone Now What?](https://forums.opensuse.org/t/re-yast-gone-now-what/196979), [openSUSE Forums - Adiós amigo Yast](https://forums.opensuse.org/t/adios-amigo-yast/196727), [YouTube - Low Tech Linux: Agama 25 and the future of YaST](https://www.youtube.com/watch?v=jF7rS2KUtNs)

## Suggestions for Improvement

*   **Provide Full Offline Installation Snapshots & Wi-Fi CLI Utilities:** Build and distribute an offline snapshot ISO for openSUSE Tumbleweed using Agama to support air-gapped deployments and emergency system repair. Additionally, include CLI wireless connection tools (such as `iwd` / `iwctl`) on minimal installation media to enable connecting to WPA2-Enterprise/802.1X wireless networks before beginning online package installation.
    *   *Codestream:* openSUSE Tumbleweed (Agama Latest)
    *   *Sources:* [openSUSE Forums - Agama offline installation media and installer defaults](https://forums.opensuse.org/t/agama-offline-installation-media-and-installer-defaults/196616)
*   **Introduce an Ncurses or Console Text Fallback Mode:** Implement a lightweight ncurses/text interface or interactive console CLI for Agama on server and Leap media. This will enable administrators on low-resolution KVMs, serial consoles, and air-gapped machines to complete installations locally when graphical Wayland/Firefox display fails and inbound browser access is prohibited.
    *   *Codestream:* openSUSE Leap 16.0 / SLES 16.0 (Agama 22), openSUSE Leap 16.1 / SLES 16.1 (Agama 24)
    *   *Sources:* [openSUSE Forums - Text-based Installation of Leap 16?](https://forums.opensuse.org/t/text-based-installation-of-leap-16/196983)
*   **Improve EFI Partition Guidance for systemd-boot:** When `systemd-boot` is chosen as the bootloader, the storage configuration screen should display explicit sizing recommendations (2–4 GiB ESP) and offer automatic resizing or a one-click fallback to GRUB2 rather than halting installation with an ambiguous partition error.
    *   *Codestream:* openSUSE Tumbleweed (Agama Latest)
    *   *Sources:* [openSUSE Forums - Newish to opensuse, doubts about yast and partitions](https://forums.opensuse.org/t/newish-to-opensuse-doubts-about-yast-and-partitions/196981)
*   **Clearer Mode Selection Explanations & Post-Install Guidance:** Include inline explanations during the initial Leap 16.1 configuration screen outlining the operational differences between Standard and Immutable modes (e.g., mutable RPM root vs. transactional update snapshots). Additionally, provide prominent post-install documentation steering new users toward Cockpit and modern package tools to ease the transition away from YaST.
    *   *Codestream:* openSUSE Leap 16.1 / SLES 16.1 (Agama 24), openSUSE Tumbleweed (Agama Latest)
    *   *Sources:* [LinuxCompatible - openSUSE Leap 16.1 Released: Immutable Mode and Unified Distro Ship Now](https://www.linuxcompatible.org/story/opensuse-leap-161-released-immutable-mode-and-unified-distro-ship-now/), [openSUSE Forums - RE: YaST Gone Now What?](https://forums.opensuse.org/t/re-yast-gone-now-what/196979)

    *   *Integrated Web Terminal Demonstration:* The host demonstrates the new browser-integrated terminal widget. Instead of standard zypper commands altering live root binaries, updates are executed via `transactional-update dup`. The command creates a new discrete Btrfs snapshot in the background. The presenter demonstrates rebooting into the newly generated snapshot.
    *   *Snapshot Rollback Demonstration:* To highlight system resilience, the presenter demonstrates `transactional-update rollback`, booting directly into an earlier read-only snapshot from the GRUB boot menu to revert unintended changes.
