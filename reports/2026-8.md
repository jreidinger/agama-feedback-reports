# Agama Web-Based Installer: Recent Feedback Report

This report summarizes internet feedback regarding the Agama web-based installer gathered over the past month. It is categorized by codestream and includes positives, negatives, and suggestions for improvement, with resolved links to the original sources.

---

## 1. Codestream: openSUSE Tumbleweed (Latest Agama Version)

### Positives
- *Blazing Fast Installation Speed:* Real-world testing shows the Agama installer completing an installation in roughly half the time compared to the legacy YaST installer.
  - Source: [YouTube - Agama Installation Testing](https://www.youtube.com/watch?v=mAY5dTFnkrQ)
- *Modernized UI & Theming:* Users highly praise the Agama 22 web-based interface (built on PatternFly), highlighting the new persistent header and Appearance tool (dark/light mode).
  - Source: Linuxiac - Agama Installer 22 Adds VLAN Setup
- *Seamless Remote Installation:* Tumbleweed administrators love the capability to control the installation remotely via a host web browser, particularly for virtual machines.
  - Source: Linuxiac - Agama Installer 22

### Negatives
- *Lack of Granular Package Control:* Power users lament the loss of YaST's fine-grained package selector. Agama relies strictly on high-level patterns, making it difficult to deselect optional dependencies.
  - Source: Reddit - General Considerations about openSUSE
- *Missing "Abort" or "Quit" Button:* Users complain there is no explicit way to safely exit the installer if they change their minds, forcing them to perform physical hard-reboots.
  - Source: openSUSE Forums - Agama Installation Experience
- *Missing WiFi Firmware:* Edge cases with hardware (such as lacking iwlwifi out of the box) frustrate users trying to complete online installations on modern laptops.
  - Source: Reddit - No network/wifi on a new Zenbook

### Suggestions for Improvement
- *Introduce a "Barebones Desktop" Option:* Provide a pattern or mechanism to bypass heavy dependencies and start from a truly minimal graphical setup.
  - Source: Reddit - General Considerations about openSUSE
- *Bake Essential Proprietary Firmware into Live Media:* Ensure standard network firmware is directly available in the installer environment so WiFi works universally.
  - Source: Reddit - No network/wifi on a new Zenbook
- *Add a Safe Exit Button:* Implement a clear UI option on the main dashboard to safely terminate the installer and trigger a graceful system reboot.
  - Source: openSUSE Forums - Agama Installation Experience

## 2. Codestream: openSUSE Leap 16.0 / SLES 16.0 (Agama 22)

### Positives
- *Powerful JSON/Jsonnet Automation:* Enterprise administrators consider the shift from legacy AutoYaST XML to programmable JSON/Jsonnet profiles a massive modernization for automated deployments.
  - Source: SUSE Documentation - SLE 16 Comparison
- *Headless & Pre-configured Server Access:* The newly introduced access configuration block in JSON profiles (allowing SSH and Cockpit pre-configuration) is praised for streamlining SLES 16.0 and Leap headless setups.
  - Source: openSUSE News - Planet Roundup
- *Multi-Product Reusability:* The ability for a single Agama 22 session to deploy a variety of modular targets (Leap, MicroOS) flawlessly is heavily appreciated.
  - Source: openSUSE Forums - Building a modular Agama product

### Negatives
- *Partitioning Nightmare for Multi-Booters:* Agama's default action to "use whole drive" alongside hidden custom partitioning options are heavily criticized by Leap users upgrading or dual-booting with Windows.
  - Source: openSUSE Forums - Agama Installation Experience
- *LVM & Encryption Failures:* Users attempting advanced storage layouts with Full Disk Encryption plus LVM on Leap 16.0 reported reproducible hanging loops during the storage preparation stage.
  - Source: openSUSE Forums - Agama LVM Questions
- *Hub-and-Spoke Navigation Fatigue:* Administrators felt that constantly returning to the main menu for each configuration step (Timezone, Network, Storage) was unnecessarily tedious.
  - Source: openSUSE Forums - Agama Installation Experience

### Suggestions for Improvement
- *Safer Defaults for Existing Partitions:* Rework the initial storage prompt to clearly offer "Use Unallocated Space" or detect existing OSes instead of defaulting to a full drive wipe.
  - Source: openSUSE Forums - Agama Installation Experience
- *Refine Custom Partitioner & Fix LVM Bugs:* Expose advanced tools (like Btrfs subvolumes and LVM setups) more intuitively and resolve the storage preparation hanging issues.
  - Source: openSUSE Forums - Agama LVM Questions
- *Optional Linear Navigation Flow:* Introduce a step-by-step "Wizard" navigation mode alongside the current hub dashboard to streamline configuration.
  - Source: openSUSE Forums - Agama Installation Experience
